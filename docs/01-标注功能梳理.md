# 屏幕标注插件 · Step 1：标注功能梳理（能力基线）

> 目的：以截图标注类工具的通用「标注」能力为参照，梳理**悬浮标注工具栏**的功能点，并据此推导**配置页面**功能点，作为后续方案与开发的输入。
>
> 调研方式：归纳同类产品的公开使用说明与实机表现，分「工具栏结构 / 通用操作 / 分工具能力 / 快捷键」四层整理。下表「来源」列只说明该配置项由哪类能力推导而来，不指向具体产品。
>
> **明确排除**：截图、贴图/钉图、长截图、录屏、OCR、翻译、保存/复制到剪贴板、图片处理（翻转/灰度等）、二维码识别、元素右键贴合。本清单只保留「标注」本身。

## 1. 悬浮标注工具栏

### 1.1 工具栏结构

| 区域 | 行为 | 说明 |
| --- | --- | --- |
| 主选区域 | 始终显示 | 放高频工具（箭头、文字、矩形、马赛克等） |
| 次选区域 | 鼠标移到右侧展开入口时显示 | 放低频工具（放大镜、水印、自动马赛克等） |
| 浮动按钮 | 显示「最近一次使用的次选区域按钮」 | 方便连续使用同一低频工具 |
| 调整/编辑按钮 | 在主选/次选之间移动按钮、排序、删除 | 入口：次选区域「调整」或 配置-标注-标注按钮调整-编辑按钮 |
| 工具栏显隐 | 可隐藏（快捷键），隐藏后需按快捷键或退出重进恢复 | 属于演讲场景的关键交互 |
| 工具栏位置 | 跟随选区/可拖动，贴边避让 | 截图场景为跟随选区；桌面覆盖层需自行定义停靠规则 |

> 注意：截图/贴图工具栏上还有「保存、复制、贴图、取消」等动作按钮，属于截图功能，本项目**不纳入**。

### 1.2 通用操作（与具体工具无关）

| 能力 | 交互细节 | 相关配置 |
| --- | --- | --- |
| 撤销 / 重做 | 工具栏按钮；Ctrl+Z / Ctrl+Y | 可自定义内置快捷键 |
| 颜色选择 | 预设色板 + 最大色块打开取色器自定义；Ctrl+滚轮 调透明度 | 色板编辑（增删/数量/排版）；所有工具共用颜色开关 |
| 线条粗细 / 尺寸 | 多数工具支持滚轮调整粗细或大小 | 铅笔最大宽度等分工具上限 |
| 二次调整 | 先切到对应工具，再点选已有标注进行编辑（控制点/位置/旋转） | 三档：禁用 / 启用 / 完全禁用（完全禁用=松手后也不能继续调整） |
| 删除标注 | 选中后 Delete / Backspace | — |
| 统一快捷键 | 见 1.4 | 内置快捷键可全部改写 |
| Shift 约束 | 矩形/椭圆 → 正方形/正圆；折线/箭头 → 45° 固定角度；铅笔 → 直线 | 铅笔直线角度档位可配 |
| 右键贴合元素 | 矩形/马赛克/橡皮擦 右键自动贴合 UI 元素范围 | 需元素识别能力；**本项目不纳入** |

## 3. 本项目范围决策（屏幕标注 / 演讲培训场景）

### 3.1 场景约束（与截图场景的本质差异）

| 维度 | 截图标注类工具 | 本插件（桌面实时覆盖） |
| --- | --- | --- |
| 底图 | 静态截图 | 实时桌面（幻灯片可能仍在动） |
| 输出 | 保存/复制/贴图 | 不产出图片，标注只存在于覆盖层 |
| 使命 | 一次成图，标注要精修 | 演讲中快速表达，追求「快、稳、不挡操作」 |
| 结束 | 保存即结束 | 需随时隐藏/穿透，随时恢复 |
| 输入 | 截图工具栏独占鼠标 | 必须能与演讲软件共存 |

### 3.2 纳入 / 排除矩阵

| 能力 | 决策 | 理由 |
| --- | --- | --- |
| 悬浮工具栏（主选/次选/排序） | ✅ 纳入 | 核心交互载体 |
| 撤销/重做、清除、删除、颜色、粗细 | ✅ 纳入 | 基础可用性 |
| 箭头、矩形、椭圆、直线、铅笔、荧光笔、文字、序列号、橡皮擦 | ✅ 纳入 | 演讲高频 |
| 聚光灯 | ✅ 纳入 | 演讲突出要点 |
| 放大镜 | ✅ 纳入 | 用户明确要求「放大」 |
| 折线 | ✅ 纳入（可后置） | 流程图/路径说明 |
| 二次编辑（选中/移动/删除） | ✅ 纳入 | 讲错要能改 |
| 点击穿透 / 隐藏标注 | ✅ 纳入 | **演讲场景刚需**，避免挡住演示软件 |
| 标注屏幕选择 | ✅ 纳入 | 演讲=投影屏，必须能指定 |
| 工具快捷键 | ✅ 纳入 | 演讲中不能翻工具栏 |
| 截图、贴图、长截图、录屏 | ❌ 排除 | 用户明确不要 |
| 保存/复制/导出图片 | ❌ 排除 | 同上（不属于标注） |
| OCR/翻译/二维码/图片处理 | ❌ 排除 | 截图工具能力，非标注 |
| 右键贴合 UI 元素 | ❌ 排除 | 依赖元素识别，非标注必要能力 |
| 评论（双击箭头） | ❌ 排除 | 单人演讲无协作评论需求 |
| 水印 | ❌ 排除（P2 备选） | 无输出图片，水印无落点 |
| 马赛克/模糊/智能擦除/自动马赛克 | ❌ 排除（P2 备选） | 实时覆盖层无法直接处理下层像素，需截屏+像素化合成，成本高、演讲无隐私遮挡诉求 |
| 扇形/弧形/旋转/文字背景等高级样式 | ⏸ P1 | 价值有但优先级低于核心链路 |

### 3.3 版本分层（建议）

**P0 · 最小可用闭环（本次开发目标）**

1. 触发：uTools 功能指令「屏幕标注」+ 用户配置全局快捷键（提供跳转设置入口）；进入即全屏透明覆盖层 + 悬浮工具栏。
2. 工具：箭头、直线、矩形、椭圆、铅笔、荧光笔、文字、序列号、聚光灯、放大镜、橡皮擦。
3. 通用：色板 + 自定义颜色、线宽/字号滚轮、撤销/重做、清除全部、选中/移动/删除、Esc 退出并清空。
4. 会话：隐藏工具栏、鼠标穿透、恢复；标注目标屏幕选择（光标所在屏/指定屏）。
5. 配置页：按钮主/次选与排序、默认颜色/线宽、目标屏幕、退出行为、快捷键；进入标注默认不预选工具。
6. 配置持久化到 `utools.db`。

**P1 · 体验完善**

- 二次编辑控制点（缩放/旋转/圆角/扇形）、文字粗斜体/描边/背景、序列号字母/罗马/注释/递补、折线连接与端点样式、放大镜高级参数（连接线/阴影/抗锯齿）、聚光灯参数、工具栏位置记忆与拖拽、快捷键自定义全量、多显示器同时覆盖。

**P2 · 增强**

- 水印、马赛克/模糊（截屏合成）、鼠标点击特效、计时器、画笔平滑优化、标注快照导出（若后续需要）。

### 3.4 与截图标注类工具的差异（刻意不做）

- 无底图：不截屏、不贴图，标注直接叠加在实时桌面上；因此所有「对图像像素做处理」的工具（马赛克/模糊/智能擦除/水印/裁剪）不在 P0。
- 面向演讲：新增截图标注类工具普遍没有的「穿透 / 隐藏标注 / 目标屏幕」会话能力。
- 放大镜实现方式不同：截图标注类工具放大静态截图局部；本插件需要瞬时捕获屏幕再放大（见 4.3）。

## 4. 技术可行性初判（影响范围的硬约束）

| 能力 | 依据 | 结论 |
| --- | --- | --- |
| 全屏透明置顶覆盖窗口 | 自定义窗口文档「全屏透明置顶窗口」示例 | ✅ 官方支持 |
| 窗口置顶到屏幕最上层 | `setAlwaysOnTop(true, 'screen-saver')` | ✅ 官方支持 |
| 指定显示器覆盖 | `getAllDisplays()` / `getCursorScreenPoint()` / `getDisplayNearestPoint()`，DIP 坐标 | ✅ 官方支持 |
| 鼠标穿透 | `setIgnoreMouseEvents(true, {forward:true})` | ✅ 官方支持 |
| 全局快捷键 | uTools 功能指令快捷键 + `redirectHotKeySetting()` / `getCmdHotKey()` | ✅ 官方支持（快捷键由用户在 uTools 中设置） |
| 放大镜取像素 | `captureDisplay({displayId})` 返回 NativeImage（物理像素），可 `toDataURL()` | ✅ 支持，但需处理「捕获到自身覆盖层」的时序问题 |
| 配置持久化 | `utools.db`（跨设备同步） | ✅ 官方支持 |
| 长时间演讲不掉线 | 文档警告：主窗口隐藏后插件应用可能按用户设定时间（默认 3 分钟）自动退出 | ⚠️ **最高风险，必须实验验证** |
| 中文输入法文字标注 | 透明窗口需可聚焦 | ⚠️ 需实机验证 IME 候选框行为 |
| 多显示器混合 DPI | 窗口按 DIP、截图为物理像素 | ⚠️ 需按显示器分别建窗并换算 |

风险处置原则：**先做「运行时可行性 Spike」再做功能开发**；若自动退出无法规避，P0 的会话模型需要调整（例如缩短单次标注、或改为「主窗口保持运行」的方案），这会直接改变方案，因此放在 Step 2 方案的第一阶段。

## 5. 进入 Step 2 前需确认的 3 个决策点

1. **范围**：是否按 3.3 的 P0 清单进入方案？（P0 已含用户要求的「标注 + 放大」）
2. **目标屏幕**：默认「光标所在屏幕」是否够用？是否必须支持「多屏同时覆盖」？
3. **退出行为**：Esc 退出后默认清空标注（推荐，避免下次演讲残留），还是保留？
