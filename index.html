      使用说明

      从配置到演讲现场的完整流程。

      1. 01

        设置全局快捷键

        在「常规」为「屏幕标注」指令设置快捷键（如 F8）。之后按快捷键会直接在鼠标所在屏幕开始标注，不需要先打开配置页。

      2. 02

        开始标注

        按全局快捷键或点击「开始标注」。默认不预选工具；也可以在「常规 → 默认激活工具」里指定每次进入时自动选中的工具。

      3. 03

        选工具、调参数

        点选工具后图标变蓝，上方出现该工具的参数条；再次点击当前工具可收起参数条。颜色、线型、字号、透明度等都可即时调整。

      4. 04

        穿透演示软件

        需要操作 PPT / 浏览器时按 F10 穿透，鼠标可直接点击底层应用且标注仍然可见。工具栏会保留，穿透按钮变蓝；再次按 F10 或点击该按钮退出，点击任意工具也会自动退出穿透并选中该工具。

      5. 05

        退出与保留

        按 Esc 退出。默认清空本次标注；关闭「退出时清空标注」后，可在同一屏幕、同一次插件运行期间恢复。

      建议：让插件随 uTools 启动常驻

      勾选「跟随主程序同时启动运行」后，插件会随 uTools 一起启动，演讲时不必等待冷启动，覆盖层和快捷键能更快就绪。

      路径：右键插件图标 → 运行设置 → 勾选「跟随主程序同时启动运行」。若该项是灰色，先取消「退出到后台立即结束运行」，再勾选自动启动。

      屏幕标注

      演讲、培训与远程讲解的实时标注层

      v0.1.0

      按全局快捷键在鼠标所在屏幕打开透明覆盖层，直接在 PPT、浏览器或任意画面上圈画、标注、放大，不打断正在演示的内容。

      当前能力

      • 12 种工具：选择、箭头、直线、矩形、椭圆、铅笔、荧光笔、文字、序号、聚光灯、放大镜、橡皮擦
      • 每个工具独立参数条：线型、箭头、填充、字体、字号、颜色、透明度、倍数
      • F10 鼠标穿透、F9 隐藏工具栏、放大镜截屏、聚光灯单层遮罩

      运行方式

      • uTools 8.0+，原生 HTML / CSS / JavaScript，无构建步骤
      • 配置保存在 utools.dbStorage；标注不写盘、不生成图片
      • 进入标注默认不预选工具，可在「常规」指定默认激活工具
      • 默认退出清空；可关闭清空以在同一会话、同一屏幕内恢复
      平台

      Windows 已验证；macOS 代码兼容，待实机验证。

      版本

      v0.1.0 · P0 范围
